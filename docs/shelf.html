Readmission is decided inside the 30 days after discharge. cost_through_day_60 keeps accumulating through that window. A readmission adds a charge of 3200 on top of a smaller length-of-stay term and Gaussian noise, so the column is a soft copy of the label. Length of stay is already available at discharge and is in both models; the future column is the only thing that changes. ROC-AUC gap (leaky minus clean): +0.2639

The leaky pipeline appends a second copy of every claim, keeping the same row_id, and then takes a stratified row split. A test row can be the twin of a training row. The clean pipeline splits the original table, where each row_id appears once. Both paths train the same random forest (200 trees, min_samples_leaf=1, n_jobs=1). An exact copy has the same features as its twin, so trees that saw the twin vote its label. The card separates accuracy on those copied test rows from accuracy on the rows that were new. A logistic regression on the same two splits cannot memorize a twin; it shows what the features support when the model does not recall the row.

502 of 720 leaky test rows share a row_id with training. The forest's accuracy on those copied rows is 1.0000. On the leaky test rows that are not copies, accuracy is 0.6422. The clean split shares none; forest ROC-AUC there is 0.6980, against 0.9618 on the contaminated split. Logistic regression is 0.7377 contaminated and 0.7350 clean.

This is a separate, matched holdout comparison. Both paths score the exact same untouched test table. Each training table has the same row count: the contaminated one receives copies of half the holdout claims, while the control receives an equal number of copies drawn from its own training rows. The model and holdout do not change. Only the presence of copied holdout rows in training changes, so the score difference is directly attributable to contamination.

Both paths score the same 360 holdout rows. The contaminated training set contains copies of 180 of them, while the control has the same training row count with no holdout copies. The leaky forest reaches ROC-AUC 0.9089; the clean forest reaches 0.7015. Accuracy is 1.0000 on copied holdout rows and 0.6556 on untouched holdout rows.

Experiment 4 · Preprocessing fit on the full table before the split

Target encoding

2,000 synthetic intake rows, one row per member id

Leaky

1.0000

Accuracy 1.0000 · AP 1.0000

1500 train rows · 500 test rows

Clean

0.7531

ROC-AUC

Accuracy 0.6800 · AP 0.7093

1500 train rows · 500 test rows

ROC-AUC gap (leaky minus clean): +0.2469

member_id is a different string on every row. It identifies that row and nothing else. The leaky pipeline fits sklearn's TargetEncoder (smooth='auto', target_type='binary') on the whole table and only then splits. For a category that appears once, the value stored by fit and read back by transform is that row's label, so the test matrix already contains the answer. The clean pipeline splits first. The encoder sits inside a Pipeline and is fit on the training rows only. Every test id is unseen, and TargetEncoder fills unseen categories with the training prevalence, a constant on the test set. fit_transform is a different call: it cross-fits, so a row does not receive an encoding built from its own label. Cross-fitting the full table is still the wrong order when a category appears on both sides of a later split. It is not the call the leaky path makes, and on these unique ids it does not paste the label back.

The encoding from fit on the full table matches the label on every row (True). Leaky ROC-AUC is 1.0000. The clean encoder is fit on 1500 training rows, and its encoding of the 500 test ids has standard deviation 0.0000. Clean ROC-AUC is 0.7531. fit_transform on the same full table correlates with the label at -0.0025.

Experiment 5 · Target encoding needs a group split, not just train-only fit

Group-aware repeated-entity encoding

360 synthetic members, 3 visits each

Leaky

810 train rows · 270 test rows

Clean

0.7440

ROC-AUC

Accuracy 0.6407 · AP 0.6600

810 train rows · 270 test rows

ROC-AUC gap (leaky minus clean): +0.2554

Each member has repeated visits and one stable outcome. The leaky path uses a random row split, but still fits the target encoder on training rows only. That is not enough: another visit from the same member is often in training, so the encoded member id carries the outcome into test. The clean path uses a group split by member_id and keeps the same encoder inside the training-only pipeline. Every clean-test member is unseen, so the encoder falls back to the training prevalence.

The random split shares 218 entities across train and test; its training-only encoder still reaches ROC-AUC 0.9993. The group split shares 0 entities, fits the same pipeline on training rows only, and reaches 0.7440. The clean test encoding has standard deviation 0.0000, because every member id is unseen.
