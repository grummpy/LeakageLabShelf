# Leakage Lab Shelf: student prompts

Use only the synthetic generators in this repository. Do not open a real record set, contact a provider, or add a network data source.

1. Predict the copied-rows card before running it. Which rows should have the highest score, and why does the existing mixed split hide that distinction?
2. Trace the matched-holdout comparison. Name the input, the shared holdout, the extra contaminated training rows, and the control's row-count match.
3. Repair the repeated-entity encoding lesson. State where the split happens, where `TargetEncoder` is fit, and what an unseen member must receive.
4. For each card, label the leak as future information, copied-row contamination, preprocessing fit scope, or group overlap. More than one label is allowed only when you can name the separate paths.
5. Run the optional CSV export and, in a separate environment, audit the two split pairs. Record exact-row versus shared-entity findings using row positions rather than raw values.

Write your prediction, trace, and repair in your own words before reading the answer key.
